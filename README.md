# Vue — Wear Your Own Story.

Motion-first fashion storefront. Static HTML/CSS/JS (no framework), generated by a ~100-line Node script.

**Live:** https://vue-fashion.vercel.app

## Pages
`/` home · `/shop` (filter, search, sort, wishlist, quick-add) · `/product/<id>` (static page per product, JSON-LD) · `/lookbook` (lightbox) · `/about` · `/contact` · `/login` (sign in / sign up) · `/account` · 404

## Develop
```bash
npm run build      # src/ -> dist/
npm run dev        # build + serve on :3000
```
- Products live in `src/data/products.json` (add a product + drop `src/assets/img/<id>.webp`, rebuild — page, sitemap and shop grid update).
- Page templates: `src/pages/*.html`, shared header/footer/head in `src/partials/`.
- Font: self-hosted variable sans registered as **"Vue"** (`src/assets/fonts`).
- Images were processed with `scripts/process_images.py` (UI-overlay inpainting, background-removed cutouts, WebP).
- Promo video: `node promo/render.cjs public/vue-promo-mobile.mp4 <site-url>` (needs Playwright + ffmpeg).

## Deploy
Vercel project `vue-fashion` is linked to this repo (`vercel.json` sets build + clean URLs + caching). Set `SITE_URL` env var if you move to a custom domain so canonical/OG/sitemap URLs update.

## Known demo limits
- Auth, cart and wishlist are **browser-only (localStorage)**: accounts are not shared across devices and checkout is simulated. Swap in Supabase/Auth.js + Stripe for production.
- Testimonials, stats (10+ yrs, 12K clients, 4.8★), contact details and prices are **placeholder copy**.
